# Code of Conduct

## Our commitment

The TIWAT project aims to provide a respectful, constructive environment for contributors and users, regardless of experience level, identity, background, or point of view.

## Expected behavior

- Be respectful, patient, and constructive.
- Discuss ideas and code, not personal worth.
- Accept feedback gracefully and offer it with care.
- Explain disagreements without insults or intimidation.
- Respect privacy. Do not publish credentials, private conversations, personal data, or non-public security details.
- Focus on what is best for the project and its community.

## Unacceptable behavior

Harassment, threats, personal attacks, discriminatory language, deliberate intimidation, doxxing, sexualized harassment, and knowingly sharing another person’s private information are not acceptable.

Spam, bad-faith disruption, and repeated disregard for project decisions or maintainer instructions may also result in moderation.

## Enforcement

Project maintainers may edit, remove, or reject contributions and may restrict participation when behavior violates this code. To report a conduct concern, contact the maintainer through the [project’s GitHub profile](https://github.com/shivatmprakash9009-eng). Do not use a public issue to disclose private or sensitive information.

This code applies in project issues, pull requests, code review, and other spaces where someone represents or participates in TIWAT.
